# VoidGifts 1.0.0

Подарки-головы для Bedrock-сервера VoidPE.

## Как это работает
1. Админ: `/gift create <тип> [кол-во]` — выдаётся голова с текстурой подарка.
2. Ставишь голову в мире (как блок).
3. Игрок нажимает ПКМ — получает награду: команды из `gifts.yml` от консоли,
   `%player%` заменяется ником нажавшего. Награда — один раз на конкретный подарок для каждого игрока.
4. Нажавшему лично играет случайный `.ogg` из `plugins/VoidGifts/music/` (8 секунд,
   настраивается `music-seconds`). Повторы за сессию не играют; перезаход сбрасывает историю.

## Файлы
- `config.yml` — общие настройки (объём, 8 секунд, путь Bedrock-пака, сообщения).
- `gifts.yml` — типы подарков: название, текстура головы (Value base64), команды награды.
- `data.yml` — размещённые подарки и кто открыл (не редактировать руками).
- `music/` — сюда кладите .ogg. При старте и `/gift reload` плагин сам пересобирает
  `VoidGiftsPack.mcpack` в `plugins/Geyser-Spigot/packs/` (можно отключить: `bedrock-pack-path: false`).
  Игрокам нужен перезаход, чтобы услышать новые треки.

## Bedrock
Текстура головы — purple present (hash 75419fce...). Хэш добавлен в `plugins/Geyser-Spigot/custom-skulls.yml` —
замени файл на новый (или допиши одну строку из него) и перезапусти сервер.
Своя голова: нарисуй скин, загрузи на mineskin.org, впиши Value в gifts.yml
и допиши хэш скина в custom-skulls.yml.

## Команды
- `/gift create <тип> [кол-во]` — получить головы (voidgifts.admin)
- `/gift give <игрок> <тип> [кол-во]` — выдать игроку (voidgifts.admin)
- `/gift list` — список типов
- `/gift reload` — перечитать конфиги, пересобрать пак (voidgifts.admin)

## Размещение/удаление
Поставил голову — подарок активен. Сломал — подарок исчезает (кто уже открыл, повторно не получит).

## Меню предметов и шансов (1.1.0)

Администратор с `voidgifts.admin` открывает `/gift menu` и выбирает тип подарка.
В меню лута нажмите на предмет в своём инвентаре: копия со всем количеством,
названием и метаданными добавится в награды, оригинал останется у администратора.
Нажмите на добавленный предмет, чтобы менять шанс кнопками −10%, −1%, +1%, +10%
или удалить запись. Новые предметы имеют шанс 100%; значения от 0% до 100%.

Каждая запись проверяется независимо при открытии: может выпасть несколько наград
или ни одной, если все проверки не прошли. Ранее настроенные команды `gifts.yml`
по-прежнему выполняются всегда и не меняются. Каждый игрок по-прежнему может
открыть конкретный размещённый подарок один раз. Предметы, не поместившиеся в
инвентарь, выпадают рядом с игроком.

Лут сохраняется автоматически в `plugins/VoidGifts/loot.yml`; `gifts.yml`,
`data.yml` и музыкальные настройки не перезаписываются. Если `loot.yml` повреждён,
открытие подарков и редактирование временно блокируется, файл не перезаписывается;
восстановите резервную копию и полностью перезапустите сервер. Для настройки
лут-меню не требуется перезапуск.
