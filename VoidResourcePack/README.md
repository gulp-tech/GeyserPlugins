# VoidPE Resource Pack 1.18.1

Пак для `plugins/Geyser-Spigot/packs/`. Сохранены UUID исходного VoidPE-пака, поэтому новая версия заменяет старую без изменения остальной конфигурации Geyser.

Изменение 1.18.1: `ui/scoreboards.json` скрывает красные значения двумя независимыми способами: отключает коллекцию `scoreboard_sidebar/main/lists/scores` и сам label `scoreboard_sidebar_score` (дополнительно задаёт ему нулевые размер и прозрачность). Это запасной вариант для клиентов и комбинаций UI-паков, где игнорирования одной коллекции недостаточно. Сам sidebar, заголовок, коллекция игроков и строки TAB не переопределяются. Числовые score в пакетах не изменяются, поэтому серверная сортировка строк сохраняется.

Сборка и проверка из корня репозитория:

```bash
python3 tools/test_voidresource_pack.py
python3 tools/build_voidresource_pack.py
python3 tools/test_voidresource_pack.py --require-output
```

После замены `.mcpack` нужен полный перезапуск сервера и повторный вход Bedrock-игрока. В папке `packs` должна быть только одна версия `VoidResourcePack.mcpack`. Проверьте в логе Geyser, что загружена версия **1.18.1** с UUID `be7304eb-1c69-4b48-a293-1f08375d08de`; если этой строки нет, клиент не получил исправление. Другой клиентский или серверный UI-пак с более высоким приоритетом также может перезаписать `ui/scoreboards.json`.
