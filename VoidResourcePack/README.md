# VoidResourcePack — иконки скорборда, логотип и графика меню (Geyser / Bedrock)

Готовый файл: **`VoidResourcePack.mcpack`** в корне репозитория.

## Что внутри (пак v1.21.0)

- `font/glyph_E1.png` — лист глифов 256×256 (сетка 16×16 ячеек по 16 px):
  иконки скорборда, устройств и рангов, **полоса логотипа** для заголовка скорборда
  и **иконки меню в стиле FunTime** (тёмная плашка + яркая объёмная иконка).
- `textures/ui/title.png` — логотип VoidPE игровым шрифтом (замена MINECRAFT на экране загрузки).
- `pack_icon.png` — иконка пака.

> Версия пака в `manifest.json` поднимается **при каждом изменении графики**:
> Bedrock кеширует паки по `uuid` + `version`, без поднятия версии игроки не перекачают пак.
> Сейчас — `1.21.0`.

## Как это работает

Bedrock не умеет картинки в скорборде и в меню, зато умеет **кастомные глифы шрифта**.
Лист `font/glyph_E1.png` — 16×16 ячеек по 16 px; ячейка `N` (0…255) соответствует символу
`U+E1NN`. Иконка = **один символ** = одна строка текста, поэтому скорборд не раздувается.

Формула: `символ = chr(0xE100 + idx)`, где `idx = строка * 16 + столбец`;
в конфигах плагинов код записывается как `E1NN`, а `idx = int("E1NN"[1:], 16) - 0x100`.

## Установка на Geyser

1. Положите `VoidResourcePack.mcpack` в **`plugins/Geyser-Spigot/packs/`**
   (для standalone-Geyser — в папку `packs/` рядом с конфигом).
2. Перезапустите сервер (или Geyser). Пак сам предложится Bedrock-игрокам при входе —
   Geyser подхватывает все `.mcpack` из `packs/`.
3. Поставьте в конфиге Geyser **`force-resource-packs: true`**: без пака на сервер не зайти,
   иначе игрок увидит «пустые квадраты» вместо иконок в меню.
4. После обновления пака игрокам нужно **переподключиться** (Geyser отдаёт новую версию пака
   при следующем входе; при `force-resource-packs: true` — принудительно).

## Свои иконки / пересборка

```bash
python3 tools/make_icons.py          # лист глифов + логотип + иконки меню (нужен pillow)
python3 tools/build_mcpack.py        # собрать VoidResourcePack.mcpack
python3 tools/make_menu_preview.py   # превью меню (preview/menu-preview.png)
```

- Иконки скорборда/устройств/рангов рисуются пиксель-арт строками в `tools/make_icons.py` (`ICONS`).
- Иконки меню — в `tools/make_menu_icons.py` (`MENU_ICONS`), рисуются кодом в 16×16
  с 8-кратным сглаживанием: добавляйте функцию и строку в словарь, свободных кодов ещё много
  (`E130`–`E13F`, `E150`+).
- Гладкие картинки из `tools/assets/*.png` перебивают пиксель-арт и ужимаются до 12–13 px.
