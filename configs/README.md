# Конфиги сервера

- `geyser-config.yml` — готовый конфиг Geyser под FaralMC (Bedrock-only, Floodgate, обязательный ресурспак). Класть в `plugins/Geyser-Spigot/config.yml`, затем рестарт.
- `DeluxeMenus-config.yml` — главный конфиг DeluxeMenus (`plugins/DeluxeMenus/config.yml`): регистрирует меню `menu`, `titles` и донат-магазин. Файлы разделов магазина класть в `plugins/DeluxeMenus/gui_menus/` с именами `shop.yml`, `shop_items.yml`, `shop_potions.yml`, `shop_pickaxes.yml`, `shop_talismans.yml`, `shop_spheres.yml`.
