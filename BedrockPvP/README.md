# BedrockPvP — экспериментальная замена VoidPvP

Плагин для Purpur/Paper 26.2 + Geyser, не используйте вместе с VoidPvP. VoidCombat остаётся без изменений. Плагин не изменяет и не отменяет урон, щиты, зачарования или вызовы других плагинов, кроме отмены Java sweep damage. Не перехватывает сетевые пакеты. Во время работы базовая скорость атаки 1024; после выхода/выключения она восстанавливается только если никто не изменил её после нас. Действующие модификаторы оружия сохраняются.

Вертикальное ограничение действует только на вертикальную составляющую отбрасывания от прямого удара игрока по игроку. Учитывает уже имеющуюся вертикальную скорость, но не гасит ранее полученный импульс от других источников. Остальные виды отдачи не меняет. Значение 0.36 блока/тик — стартовая настройка, проверяйте в игре с несколькими CPS, зачарованиями, спринтом и античитом.

Броня: износ надетых шлемов/нагрудников/поножей/ботинок от любых источников в среднем уменьшается до 2/3 величины после обычной обработки Unbreaking ядром. Целые очки износа округляются случайным образом, то есть отдельный удар может ничего не снять или снять как обычно, а средняя прочность возрастает примерно в 1.5 раза. Элитры, щиты и оружие не меняются.

Это **не полный порт Bedrock**: в частности Java/Purpur по-прежнему рассчитывает базовый урон мечей/топоров, эффекты, щиты, чары, крит, время неуязвимости и прочие правила. Отмена урона от sweep не гарантирует отсутствия всех визуальных эффектов. Потребуются реальные тесты на всех используемых Bedrock-версиях, в частности 1.21.130. Не обещается исправление кика: его первопричина ещё не установлена. Если клиент всё равно вылетает, нужен текст отключения.

Сделайте резервную копию, остановите сервер, уберите VoidPvP JAR из plugins, установите BedrockPvP, запустите сервер и проверьте. Не выключать VoidCombat. Не делать /reload. Настройки в `plugins/BedrockPvP/config.yml`, для применения полный перезапуск. Возврат: убрать BedrockPvP, вернуть VoidPvP и перезапустить сервер.
