# Перенос VoidPE на PowerNukkitX: подготовка

Исходная точка: `94f74f5` ветки `arena/41da8305-geyserplugins`. Старые проекты, ресурспаки и маппинги не изменены. `PowerNukkitX-beta.zip`, `WorldEdit-version-7.4.x.zip` и `WorldGuard-version-7.0.x.zip` — оригинальные архивы пользователя.

## Найдено в исходном коде PNX

- Пространство имён API — `org.powernukkitx`, а не Bukkit/Paper. Сборка PNX настроена на Java 25. Не следует считать Bukkit JAR совместимыми с PNX.
- `NetworkConstants.CODEC` использует `Bedrock_v2225`; `RequestNetworkSettingsHandler` и `LoginHandler` отклоняют несовпадающий протокол. README этого архива указывает Bedrock 26.60. Поддержка старых 1.21.x из коробки не подтверждается и потребует отдельного решения и проверки протоколов, блоков и предметов.
- `inventory.fake.FakeInventory` и `FakeInventoryType` содержат CHEST и DOUBLE_CHEST, обработчики предметов и закрытия. Это основание для реализации инвентарных меню на Bedrock, но работа с пользовательскими предметами, защита от дюпов и закрытие при отключении/ошибке требуют отдельных тестов. Обычные формы применять там, где они не ухудшают функциональность.
- Реализованы загрузка resource pack (`ZippedResourcePackLoader` принимает zip и mcpack) и API custom items. Маппинги Geyser нельзя автоматически считать маппингами PNX; ресурспаки нужно проверять по составу, приоритетам и ID в реальном клиенте.
- В предоставленных деревьях WorldEdit и WorldGuard нет готового модуля PNX. Их API, адаптер мира/игрока/команд/прав и события защиты требуют отдельного порта; простая перекомпиляция Bukkit-модуля не подходит. Сохранять исходные лицензии и авторство.

## Порядок работ

1. Пользователь подтвердил: новый мир и вайп данных игроков, ядро PNX переписывать не требуется. Не изменять и не устанавливать старый сервер; перед любыми заменами сохранить независимую копию сервера.
2. Поднять точную сборку PNX из предоставленного архива на отдельном тестовом сервере, зафиксировать сборку, доступные API и тестовый клиент. Старый сервер не менять.
3. Реализовать и протестировать платформенный слой: идентичность Bedrock, права, события, предметы, GUI и экономика. Не включать опасные несовместимые плагины без эквивалента API.
4. Переносить плагины в отдельные проекты PNX с тестами и миграцией данных; инвентарные GUI — FakeInventory, не заменяя нужные инвентарные операции формами. Сверять команды, права, награды, автопак и конфиги.
5. WorldEdit и WorldGuard — отдельные проекты с адаптерами PNX; проверить совместимость защиты, флагов, сохранения регионов, редактирования блоков и зависимостей наших плагинов. Не отключать защиту при ошибке.
6. Переносить предметы, маппинги и паки после установления формата PNX; проверять внешний вид, метаданные, стаки, крафт, инвентари и переподключение Bedrock. Аудио автопак VoidGifts сохранить.
7. Проверить на тестовом сервере с реальными клиентами, в том числе рестарт/перенос данных, многопользовательские операции, дюпы и нагрузку. Только после этого выдавать конкретные готовые сборки и инструкции установки.

## Текущий статус

Подготовлены анализ и архив бэкапа файлов репозитория. Начат перенос VoidNV в `PNX-port/VoidNV`: CI собрал его на предоставленном PNX, успешно запустил сервер и проверил консольные команды; подключение игрока Bedrock, поведение эффекта, смерть и кулдаун в игре не проверялись. VoidMusic также перенесён отдельно: CI собрал его, PNX загрузил исходный Bedrock-ресурспак и прошли консольные smoke-тесты; воспроизведение звука и смену мира реальным игроком не проверяли. Начата экспериментальная основа адаптера WorldEdit/WorldGuard в `PNX-port/EngineHubBridge`: код координат и запросов к менеджеру регионов; CI 46181783094 собрал адаптер против исходных PNX, WorldEdit и WorldGuard и проверил координаты, регионы, измерения и приоритеты. Это не плагин и защита не реализована. Перенос VoidRtpZone отдельно начат; сборка и проверка команд/перезапуска на PNX успешны, выделитель и RTP с реальным игроком не проверены. Остальные плагины и маппинги ещё не перенесены. VoidNick и VoidQuiet пользователь попросил оставить без изменений; в переносе они не участвуют. Бэкап репозитория не заменяет отдельного бэкапа работающего сервера.


## Учёт переноса

| Компонент | Состояние | Важные зависимости / проверка |
|---|---|---|
| VoidNV | исходный код PNX, CI и запуск сервера/консоль успешны | Вход Bedrock, эффект, смерть и кулдаун не проверены |
| VoidMusic + VoidMusicPack | исходный код PNX, CI, загрузка существующего пака, запуск сервера/консоль успешны | Исходный VoidMusic использует готовый пак; звук и переходы миров на клиенте не проверены |
| VoidNick, VoidQuiet | не трогать по указанию пользователя | Исходники отсутствуют; совместимость с PNX не установлена |
| VoidAntiCheat, VoidCases, VoidClans, VoidCombat | не начато | Права, бой, защита данных, экономика, инвентарные меню |
| VoidDrops, VoidEnchants, VoidGifts, VoidItems | не начато | PNX-экономика, метаданные предметов, лут, GUI, дюпы; VoidGifts: автопак из папки music ещё не перенесён, его обязательно сохранить |
| VoidShulker, VoidTalismans, VoidWardenCity | не начато | Контейнеры, совместимость предметов, защита и данные сундуков, GUI |
| VoidPvP, BedrockPvP | не начато | Не ставить оба одновременно; боёвка и кики требуют отдельной проверки |
| VoidRtpZone | исходный код PNX, CI и консольные команды/перезапуск успешны | Реальный Bedrock, выделитель и вход в зоны, права и совместимый RTP не проверены |
| VoidTab, VoidAuthSpawn | не начато | Возможности PNX, API авторизации, взаимодействие с UI |
| VoidAnvilExtension, VoidVersionsExtension, VoidCommandsExtension, GeyserDropFix | не начато | Это расширения Geyser, нельзя просто загрузить на PNX; ядро не переписывать |
| WorldEdit и WorldGuard | начата основа адаптера; CI запросов регионов успешен, не готово к установке | Нужны адаптеры миров, блоков, игроков, команд, событий, прав и хранилища; совместимость и защита не подтверждены |
| Остальные ресурспаки и маппинги | не начато | Geyser-мэппинги не формат PNX; проверять идентичность и внешний вид предметов в клиенте |

Старые исходники в корне репозитория и оригинальные архивы WorldEdit/WorldGuard не изменяются.
