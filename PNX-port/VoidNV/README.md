# VoidNV для PNX — экспериментальный перенос

Исходный проект Bukkit оставлен отдельно в корне репозитория. Этот вариант использует API `org.powernukkitx` из пользовательского `PowerNukkitX-beta.zip`: `/nv`, `/voidnv reload`, `voidnv.use`, `voidnv.admin`, кулдаун, сообщения, эффект до смерти. Цвета `&#RRGGBB` приближённо переводятся в ближайший стандартный цвет Bedrock. Отключение и переподключение не сбрасывает кулдаун до перезапуска сервера.

Проверки CI: проект скомпилирован против предоставленного исходного кода PNX; проверены вспомогательная логика, запуск на изолированном PNX и консольные команды. Реальная игра на Bedrock не проверялась; сборка остаётся экспериментальной и не предназначена для установки на основной сервер. Совместимость с другими сборками PNX не гарантирована. GitHub Actions собирает API из предоставленного архива без изменения исходников ядра, затем компилирует этот плагин и запускает отдельные тесты вспомогательной логики. Это не заменяет тест запуска и проверки действий игроков на сервере.
