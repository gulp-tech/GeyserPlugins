# VoidRtpZone для PNX — экспериментальный порт

Отдельный PNX-проект; Bukkit-плагин и его исходники сохранены. Команды `/rtpzone` и `/rtpz`: `wand`, `save <имя>`, `remove <имя>`, `delete <имя>`, `list`, `reload`. Зона запускает настроенные команды от игрока (по умолчанию `/rtp`) или консоли, с кулдауном, пропуском режимов и правом `voidrtpzone.bypass`. Сам RTP этот плагин **не реализует**: нужен совместимый PNX-плагин с командой `/rtp`.

Выделитель помечен серверными NBT-данными, а не только названием; нажатия на блоки отменяются. В Bedrock левая и правая точки требуют проверки на реальном клиенте. Важны также проверка работы защиты других плагинов, RTP, нескольких миров и отложенных телепортов. Старый `zones.yml` читается, но файлы без `dimension` считаются измерением 0 (верхний мир), поэтому старые зоны иных измерений надо пересоздать. Имена зон — латинские буквы, цифры, `_` и `-` (до 64 знаков). Дополнительный `dimension` предотвращает пересечение областей в разных измерениях одного мира. Новые записи атомарны и не перезаписывают файл при ошибке загрузки.

На Bedrock произвольный Java-цвет `&#RRGGBB` заменён приближённым стандартным цветом. Не считать готовым к основному серверу, пока не пройдены реальные клиентские тесты и не установлен совместимый RTP.
