# VoidGifts для PNX — в работе

Это пока только часть будущего плагина: генератор Bedrock-пака музыки, хранилище размещённых подарков/получений и проверочный код. **Подарки, команды `/gift`, выдача наград и сундуковые меню ещё не перенесены. Устанавливать вместо VoidGifts нельзя.**

Генератор сканирует `plugins/VoidGifts/music/*.ogg` и создаёт соответствующие `voidpe:gift_*` ID без ручного редактирования `sound_definitions.json`. Сохраняет UUID и увеличивает версию только при изменениях, учитывает совпадающие имена, проверяет Ogg-заголовок и пределы размера, пишет отдельный временный файл и не трогает действующий пак при ошибке. Проверка сигнатуры Ogg не гарантирует исправность аудиокодека.

Путь готового пака — `resource_packs/VoidGiftsPack.mcpack` **в корне PNX-сервера**, не в Geyser. В PNX менеджер паков запускается до плагинов; при холодном запуске, до включения сети, тестируемый адаптер ставит проверенный пак и обновляет менеджер. Во время работы изменённый пак только подготавливается; для активации нужен **полный перезапуск**, а не `/reload`, поскольку PNX хранит загруженные байты в памяти и читает размер из файла. Новый список звуков нельзя использовать для игроков до активации нового пака. Проверочный `GiftPackProbe` служит только для CI и не является плагином подарков.

Хранилище регистрирует позицию (включая измерение), атомарно записывает получение до выдачи наград и сохраняет отметки после удаления подарка, как старый плагин. Ошибка записи не должна считаться успешным получением. Это защита от повторного принятия, а не гарантия выдачи при сбое сервера после записи. Данные в новом формате; миграции старого `data.yml` нет (выбран новый мир).

В разработке PNX-хранилище лута: снимки предметов в Bedrock NBT, шансы и сохранение без перезаписи при ошибке. Импорт старого Bukkit `loot.yml` и пользовательские предметы требуют отдельной адаптации и проверки.

Подготовлены также независимые процентные розыгрыши наград и выбор неповторяющейся музыки; они пока не подключены к игровым событиям.

Осталось подключить код к настоящему PNX VoidGifts, реализовать награды, команды, музыку и виртуальные сундуковые меню, а также проверить дюпы, права, воспроизведение и вид на Bedrock. Ранее сохранённые исходники не изменены.
