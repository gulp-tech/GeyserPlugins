# VoidGifts для PNX — в работе

Это пока только часть будущего плагина: генератор Bedrock-пака музыки и проверочный код. **Подарки, команды `/gift`, выдача наград и сундуковые меню ещё не перенесены. Устанавливать вместо VoidGifts нельзя.**

Генератор сканирует `music/*.ogg` и создаёт соответствующие `voidpe:gift_*` ID без ручного редактирования `sound_definitions.json`. Сохраняет UUID и увеличивает версию только при изменениях, учитывает совпадающие имена, проверяет Ogg-заголовок и пределы размера, пишет отдельный временный файл и не трогает действующий пак при ошибке. Проверка сигнатуры Ogg не гарантирует исправность аудиокодека.

В PNX менеджер паков запускается до плагинов; при холодном запуске, до включения сети, тестируемый адаптер ставит проверенный пак и обновляет менеджер. Во время работы изменённый пак только подготавливается; для активации нужен **полный перезапуск**, а не `/reload`, поскольку PNX хранит загруженные байты в памяти и читает размер из файла. Новый список звуков нельзя использовать для игроков до активации нового пака. Проверочный `GiftPackProbe` служит только для CI и не является плагином подарков.

Осталось подключить код к настоящему PNX VoidGifts, реализовать сохранение данных и наград, команды, музыку и виртуальные сундуковые меню, а также проверить дюпы, права, воспроизведение и вид на Bedrock. Ранее сохранённые исходники не изменены.
