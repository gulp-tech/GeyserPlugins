# VoidMusic для PowerNukkitX — перенос в разработке

Этот проект отделён от исходного Bukkit/VoidMusic. Сохраняются настройки world, sound, volume, pitch, длительность и пауза, команды `/vmusic` и `/voidmusic`, права `voidmusic.admin` и `voidmusic.stop`, а также персональная остановка звука и пауза. Игрока в другом мире после переключения выключаем без отправки звуков другим людям. Для Bedrock-ников с пробелами аргументы имени объединяются.

Используется существующий Bedrock-ресурспак `VoidMusicPack-v1.0.1.mcpack` из корня репозитория; на PNX пакет предполагается размещать в `resource_packs/`, а не в папке Geyser. Его загрузка и слышимость, переходы между мирами, mute, поведение при повторном входе и пакетные операции надо проверить настоящим Bedrock-клиентом. До таких тестов проект экспериментальный, а не готовая установка на основной сервер. Загрузка PNX-сервера, консольные команды и чистая логика проверяются отдельно CI.
